# Project Rules

## API Reference Compliance

- **Обязательное правило:** При каждом изменении или написании скрипта обязательно смотреть в файл [api.md](./api.md).
- Использовать только существующие функции, типы и сигнатуры из Project Vector Lua API Reference (pi.md).
- Не использовать гипотетические или несуществующие методы.
